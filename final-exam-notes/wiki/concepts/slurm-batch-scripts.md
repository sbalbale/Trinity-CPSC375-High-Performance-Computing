# Slurm Batch Scripts

> [!abstract]
> **Slurm Batch Scripts** are bash scripts used to submit jobs to the [[slurm]] scheduler. They contain both the executable commands and **#SBATCH directives** that specify the required hardware resources.

## Core Mechanics

### Common Directives
| Directive | Purpose | Example |
| :--- | :--- | :--- |
| `--job-name` | Sets a descriptive name for the job. | `--job-name=sieve_sort` |
| `--nodes` | Number of physical nodes requested. | `--nodes=4` |
| `--ntasks-per-node` | Number of MPI processes per node. | `--ntasks-per-node=12` |
| `--output` | File path for standard output (`%j` is JobID). | `--output=res_%j.log` |
| `--time` | Maximum wall-clock time (HH:MM:SS). | `--time=00:30:00` |

> [!code] Standard Launch Pattern
> ```bash
> #!/bin/bash
> #SBATCH --nodes=2
> #SBATCH --ntasks-per-node=16
> srun ./my_program
> ```
The `srun` command is critical as it handles the spawning of the MPI processes across the allocated nodes using the hostfile generated by Slurm.
