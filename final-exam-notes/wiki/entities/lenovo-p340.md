# Lenovo P340

> [!abstract]
> The **Lenovo P340 SFF** is a small-form-factor workstation used as a compute node in departmental labs. It serves as the baseline hardware for many OpenMP performance benchmarks and assignments.

## Hardware Specifications
- **CPU**: Intel Core i7-10700.
- **Cores**: 8 physical cores.
- **Threads**: 16 logical processors (via Hyper-Threading).
- **Architecture**: Shared-memory (SMP).

## Connections
* **Architecture:** [[shared-memory-model]].
* **Used For:** [[openmp]] benchmarking.
* **Contrasts With:** [[pine-cluster]] (Distributed memory).
