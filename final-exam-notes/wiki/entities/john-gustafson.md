# John Gustafson

> [!abstract]
> **John Gustafson** is a computer scientist and businessman, best known for challenging Amdahl's Law by introducing **Gustafson's Law** (or Slalom), which suggests that parallel systems can achieve linear speedup if the problem size is allowed to grow.

## Key Contributions
- **Gustafson's Law**: Argues that for large problem sizes, the parallelizable portion dominates, making massively parallel processing practical.
- **Energy-Efficient Computing**: Pioneer in many-core and low-power parallel architectures.

## Connections
* **Associated Concept:** [[gustafsons-law]].
* **Field of Study:** Scalable computing, floating-point arithmetic.
