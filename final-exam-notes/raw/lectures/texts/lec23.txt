The Sieve of Eratosthenes
An ancient algorithm that identifies all prime numbers up to a
specified limit by iteratively marking the multiples of each
discovered prime, starting from 2, as composite.
1. Create a list of unmarked natural numbers 2, 3, …, n
2. k  2
3. Repeat
(a) Mark all multiples of k between k2 and n
(b) k  smallest unmarked number > k
until k2 > n
4. The unmarked numbers are primes

Block Decomposition Options
• Balances loads – divide the array into p continuous blocks of
roughly equal size.
• More complicated to determine the owner if n is not a
multiple of p. e.g.,
– e.g., Suppose n = 1024 and p = 10, which means 1024/10 = 102.4.
– If we give every process 102 elements, there will be four left over.
– On the other hand, we cannot give every process 103 elements,
because the array is not that large.

– We cannot simply give the first p - 1 processes n/p combinations
and give the last process whatever is left over, because there may

• Allocating no elements to a process is undesirable (why?).

Block Decomposition Options
• Want to balance workload when n not a multiple of p
• Each process gets either n/p or n/p elements
• Seek simple expressions
– Find low, high indices given an owner
– Find owner given an index

Method #1
• Let r = n mod p
• If r = 0, all blocks have same size
• Else
– First r blocks have size n/p

Block Decomposition Macros
#define BLOCK_LOW(id,p,n) ((i)*(n)/(p))
#define BLOCK_HIGH(id,p,n) \
BLOCK_LOW((id)+1,p,n)-1)

#define BLOCK_OWNER(index,p,n) \
(((p)*(index)+1)-1)/(n))
#define BLOCK_SIZE(id,p,n) \
(BLOCK_LOW((id)+1)- BLOCK_LOW(id))
