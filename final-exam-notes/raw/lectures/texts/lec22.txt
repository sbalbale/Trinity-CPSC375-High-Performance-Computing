Derived datatypes
• Used to represent any collection of data items in memory by
storing both the types of the items and their relative locations
in memory.
• The idea is that if a function that sends data knows this
information about a collection of data items, it can collect the
items from memory before they are sent.
• Similarly, a function that receives data can distribute the items
into their correct destinations in memory when they’re
received.

Derived datatypes

The ACID Properties
• Atomicity: Every operation within a transaction is bound
together as a single atomic unit.
• Consistency: A transaction must transition the database
from one valid state to another correctly.
• Isolation: The system must ensure the final state is
identical to the state that would have occurred if they
had been run one at a time.
• Durability: Once a transaction is finalized (committed), its
changes are recorded in non-volatile storage.
